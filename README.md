# Andaré con Cristo — Campamento 2026

Sitio informativo del campamento de Hombres y Mujeres Jóvenes de la Estaca Kennedy
(Bogotá), del 5 al 7 de octubre de 2026 en CampoBase Suesca.

Publicado en https://sharian25.github.io/campSA2024/

HTML, CSS y JavaScript planos, sin paso de compilación. Todas las rutas son
relativas porque el sitio vive en un subdirectorio de GitHub Pages.

    index.html        Página completa
    css/styles.css    Estilos propios (se cargan después de Bootstrap)
    js/main.js        Cuenta regresiva, lista de equipaje, visor de fotos, video
    assets/images/    Fotos del lugar y logo del campamento
    assets/og-image.jpg  Vista previa para WhatsApp (1200 × 630)

Los datos que faltan por confirmar están marcados en el código con `TODO:`.
